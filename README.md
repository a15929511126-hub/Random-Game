# Random-Game
今天也没出大问题

一个非常认真的小游戏。

认真地让你每天遇到一些莫名其妙的事情。

⸻

怎么玩？

你醒来。

然后你会发现：

今天好像也没什么特别的。

直到……

一只鸭子出现在你面前。

你需要做出选择。

你的选择会改变你的状态，也可能改变之后发生的事情。

至于最后会发生什么——

我也不知道。

⸻

开始

需要：

* Python 3.8+
* 一点时间
* 一点好奇心
* 对鸭子的基本尊重

不需要安装任何第三方库。

下载仓库后运行：

python game.py

如果你的电脑使用 python3：

python3 game.py

就可以开始。

⸻

游戏里的东西

❤️ 生命

生命值归零，游戏结束。

请不要死。

虽然游戏可能会努力让你死。

🧠 心情

决定你今天过得开不开心。

有时候比钱重要。

有时候没有用。

💰 金钱

可以买东西。

也可能因为一些非常荒谬的事情消失。

🍀 幸运

有时候你只是运气好。

没有别的解释。

🌪️ 混乱

这是游戏里最危险的数值。

你的行为越离谱，混乱值越高。

混乱值越高，

这个世界就越不正常。

⸻

最重要的规则

没有正确答案。

你可以做任何你想做的事情。

比如：

发现一只鸭子。

你可以：

1. 绕开它
2. 给它吃的
3. 问它叫什么
4. 和它握手

……

为什么会有第四个选项？

不知道。

⸻

隐藏事件

有些事情不会立刻产生结果。

你今天做的选择，

可能会在几天之后回来找你。

所以如果某一天你突然发现：

“等等，这不是我前几天干的事情吗？”

恭喜。

世界记住了。

⸻

成就

游戏里藏着一些奇怪的成就。

有些很容易。

有些需要你做出非常奇怪的选择。

还有一些……

不会告诉你怎么获得。

自己发现。

⸻

存档

游戏会自动保存。

存档文件：

save.json

如果想重新开始，可以删除 save.json。

⸻

作者的话

这个游戏没有什么宏大的目标。

就是想做一个：

打开 Python 就能玩的，很小、很怪、偶尔很好笑的游戏。

如果你玩到了奇怪的事情，

请不要怀疑自己。

这就是游戏本来应该发生的事情。

⸻

最后一件事

如果你遇到了一只鸭子。

请谨慎做出选择。
