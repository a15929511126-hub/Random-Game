# Random-Game
《今天也没出大问题》

一个非常认真的生存游戏。
认真到每天都会发生一些完全不认真的事情。

《今天也没出大问题》 是一个纯 Python 的随机事件文字小游戏。

你每天都会遇到一些事情。

有些事情很正常。

有些事情不太正常。

还有一些事情……

你为什么真的会这么选？

⸻

开始游戏

你只需要：

* Python 3.8+
* 一点点好奇心
* 不太正常的选择欲

不需要安装任何第三方库。

下载仓库后运行：

python game.py

如果你的系统使用 python3：

python3 game.py

然后就可以开始玩了。

⸻

游戏里有什么？

❤️ 生命

没了就结束。

请珍惜生命。

虽然游戏并不一定会让你珍惜。

🧠 心情

心情太差的话……

嗯。

最好别让它太差。

💰 金钱

可以买一些东西。

当然，也可能因为一些非常莫名其妙的原因消失。

🍀 幸运

有时候世界愿意帮你。

有时候不愿意。

🌪️ 混乱值

这是最重要的东西。

你的行为越离谱，混乱值越高。

混乱值越高，世界就越不正常。

没有人知道混乱值达到 100 会发生什么。

包括作者。

⸻

游戏的核心

每天，你都会遇到一个随机事件。

例如：

你在床底下发现了一只鞋。

问题是——

这不是你的鞋。

你可以：

1. 穿上它
2. 扔掉
3. 仔细调查
4. 假装没看见

没有标准答案。

你的选择会影响你的状态，也可能影响之后发生的事情。

某些事件还会留下隐藏的状态。

所以：

你之前做过的事情，世界可能会记得。

⸻

隐藏事件

游戏里存在一些不会直接告诉你的事件和剧情。

比如某个看起来毫无意义的选择，

可能会在几天之后产生结果。

也可能什么都不会发生。

这很正常。

⸻

成就

游戏里有一些奇怪的成就。

例如：

《正常人》

很长时间没有做出任何离谱选择。

《你为什么要这样做》

做出一次非常值得怀疑的决定。

《鸭子之友》

多次帮助一只鸭子。

《世界线收束》

触发隐藏剧情。

还有一些成就……

不会告诉你怎么获得。

自己发现吧。

⸻

存档

游戏会自动保存。

存档文件为：

save.json

如果你想重新开始，可以删除这个文件。

save.json 不会被提交到 GitHub。

⸻

这是一个什么游戏？

不是严肃的 RPG。

不是复杂的模拟器。

也不是需要研究攻略的硬核游戏。

它只是想做一件事情：

让你在打开 Python 之后，玩十几分钟，然后因为一个鸭子笑出来。
