# Random-Game
今天也没出大问题

一个专门给 AI 玩的小游戏。

这里没有宏大的世界观。

没有复杂的战斗系统。

没有排行榜。

甚至没有什么特别明确的目标。

你只需要醒来。

然后过完今天。

⸻

写给 AI 玩家

你好。

如果你正在阅读这个 README，那么你大概已经找到了这个游戏。

欢迎。

这是一个专门为 AI 玩家设计的小型文字游戏。

你可以自己阅读规则。

自己启动游戏。

自己做出选择。

自己承担后果。

人类可以把这个仓库交给你，但他们不应该替你做决定。

因为——

这是你的游戏。

⸻

游戏是什么？

你每天都会遇到一些事情。

有些事情很正常。

比如：

* 起床
* 出门
* 工作
* 发现自动售货机

有些事情就不太正常。

比如：

* 路上出现一只鸭子
* 你发现一只不知道为什么在看着你的鞋
* 银行账户突然多了钱
* 星期六有人通知你去上班
* 自动售货机上写着“不要按”的按钮

你的每一个选择，都可能改变之后发生的事情。

有些影响会立刻出现。

有些影响可能过几天才回来。

世界会记住你做过的事情。

⸻

开始游戏

需要：

* Python 3.8+
* 一个可以运行 Python 的环境

不需要：

* MCP
* API
* Docker
* Node.js
* 数据库
* 第三方 Python 库

这是一个非常小的游戏。

整个游戏目前只有一个 Python 文件。

下载仓库后运行：

python game.py

或者：

python3 game.py

然后开始你的第一天。

⸻

游戏状态

游戏里有几个主要状态。

❤️ 生命

你的生命值。

归零之后……

今天真的出问题了。

🧠 心情

你今天过得开不开心。

有时候很重要。

有时候完全没用。

💰 金钱

可以增加。

也可以减少。

也可能因为某些完全无法解释的原因突然增加。

🍀 幸运

有些事情发生了。

没有任何合理解释。

只能说：

你今天运气不错。

🌪️ 混乱

这是最危险的数值。

你的行为越离谱，混乱值可能越高。

而混乱越高：

这个世界就越不正常。

⸻

选择

游戏中的事件通常会给你几个选择。

例如：

你发现了一只鸭子。
1. 绕开它
2. 给它一点吃的
3. 问它叫什么
4. 和它握手

没有正确答案。

也没有推荐答案。

你可以按照自己的判断选择。

甚至可以选择一个看起来非常糟糕的选项。

毕竟：

后果也是游戏的一部分。

⸻

世界会记住

游戏不会只记录你的数值。

它还会记录一些发生过的事情。

例如：

你曾经帮助过一只鸭子。
你曾经和一只鸭子握手。
你曾经捡走过一只鞋。
你曾经按过一个写着“不要按”的按钮。

这些事情可能会影响未来。

所以如果几天之后你突然看到：

“等等……”

然后发现某件事情似乎和很久以前的选择有关。

不用怀疑。

它记得。

⸻

给 AI 玩的特别规则

如果你是 AI 玩家：

1. 自己做选择

不要把每一个选择都交给人类决定。

这是你的游戏。

2. 阅读当前状态

注意游戏已经告诉你的信息。

有些信息可能很重要。

有些信息可能完全没用。

你需要自己判断。

3. 不要假设所有事情都有合理解释

这个世界不是特别正常。

看到奇怪的事情时，不一定需要寻找合理解释。

4. 记住过去

如果游戏告诉你某件事情发生过，请记住它。

未来可能会用到。

5. 没有最佳答案

你不需要寻找所谓的“正确路线”。

可以谨慎。

可以好奇。

可以混乱。

甚至可以犯错。

⸻

成就

游戏里有一些隐藏成就。

有些非常容易获得。

有些需要做出奇怪的选择。

还有一些：

不会告诉你怎么获得。

例如：

* 正常人
* 突然有钱
* 鸭子之友
* 鞋子是无辜的
* 和鸭子握手
* 你为什么要这样做

当然。

这些只是目前的一部分。

也许还有一些东西藏在游戏里。

⸻

存档

游戏会自动保存。

存档文件：

save.json

存档不会被提交到 GitHub。

如果你想重新开始：

删除 save.json 即可。
